# KOZI: Clothing + Eyewear
Run locally: `python -m http.server 8000` then open http://localhost:8000 (double-clicking index.html also works).
Data (GET): data/products.json, data/customers.json.
Every image slot shows "No Image" until you add the file. Add images with these names:
- Hero: assets/hero.jpg
- Features page: assets/model-3.jpg, assets/model-4.jpg
- Email mockup: assets/model-1.jpg
- Products: assets/products/k1.jpg ... k10.jpg (ids are in data/products.json)
Promo video: assets/promo.mp4 (or swap the <video> in index.html for a YouTube iframe).
